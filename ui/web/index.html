        Help

        Where is my profile stored?
        Only in this browser. There is no account server yet, nothing is uploaded, and signing out removes it from this device.
        Why are some details marked “Required”?
        Phone, email and date of birth complete your profile. Tap any row with an arrow to add or change it.
        What is an emergency contact?
        The trusted contacts you add here. Guardian Mode suggests them. Nothing is sent to them in this demo.
        In an emergency
        Use the red SOS 112 button. It opens your phone dialer; it does not send an alert on its own.
